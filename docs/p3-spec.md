# P3: 外部セッションとファイル・差分パネル

## ユーザーの選択（2026-11-13）

- 外部セッション取り込みとファイル・差分パネルの両方を進める。
- 外部セッションは Codex / Claude Code の両方。
- 続きを送ると元のセッションを再開する。
- 一覧はアプリの会話と混ぜる。外部由来やエージェント名のラベルを追加しない。

## 実装済み: 外部セッションの一覧・履歴・再開

- 登録プロジェクトに作業ディレクトリが一致するセッションを発見する。シンボリックリンクは実体パスでも照合する。
- ブラウザを開いたとき、フォーカス復帰時（60秒間隔）、一覧の更新ボタンで発見する。
- `.env` で利用可能な実行元だけを対象にする。Claude はサブスク有効ならその実行元、無効で API キー設定済みなら API 実行元を使用する。同じ Claude セッションを二重に表示しない。
- 同じネイティブIDがすでにアプリの会話に紐付いている場合は追加しない。
- 履歴は開くとき・会話の更新ボタン・フォーカス復帰時・送信前に同期する。
- 通常の文章、思考、ツール呼び出し・結果を既存のブロックに変換する。履歴にない使用量やモデル情報は推測しない。
- アプリが送ったターンはネイティブIDで照合する。Claudeの古いSDKでUUIDが返らない場合だけ送信した全文で照合する。
- 元のセッションが知っている履歴は再注入しない。別のモデルとの会話は従来どおり引き継ぐ。
- 再開失敗時は新しいセッションへ自動で切り替えない。
- Codex の再開は専用の app-server 接続を使い、終了時に閉じる。前回のプロセス内に残った履歴を再利用せず、CLIでの追加分をディスクから再開する。
- 承認は既存の `Run.ask` / `.env` 上限を通す。
- 改名・ピン留め・非表示・削除は現状のアプリ内操作。元のCLI履歴を削除しない。アプリで削除した会話は再発見で復活しない。
- 元セッションの巻き戻しや削除を、保存済みアプリ履歴の削除としては同期しない。同じCLIセッションを別プロセスから同時に操作するためのロックは提供しない。
- DBマイグレーション `0004`: `external_sessions` と `messages.native_origin`。

参考: [Codex App Server の公式仕様](https://developers.openai.com/codex/app-server)。実際のフィールドはインストール済みCLIの生成JSON Schemaと照合。Claudeはインストール済みAgent SDKの `list_sessions` / `get_session_messages` を使用。

## 次の段階: ファイル・差分パネル（実装承認済み）

以下の初期実装案を提示後、ユーザーから実装指示を受けた。

- フォルダを開いたときに読み込むファイルツリー。
- テキスト・コードと画像の閲覧。編集機能は付けない。
- gitの未コミット変更全体をステージ済み／未ステージに分けて表示。未追跡ファイルも一覧に出す。
- PCはCode画面の右側に開閉式パネル。スマホは会話に重ねるシート。

見た目の案:

```text
PC:   [ 会話・入力欄 ][ ファイル | 差分 ]
スマホ: [ ファイル | 差分  閉じる ] が会話に重なる
```

ファイル・差分パネルはまだ実装していない。
